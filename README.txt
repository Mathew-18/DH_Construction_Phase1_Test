DH Construction - Phase 1
========================

This ZIP contains the generated static site from commit
9dbc40881f20943066520c83cf27dc0230576967. GitHub Pages can serve
the included HTML, CSS and JavaScript directly.

1. Extract the ZIP. Open your separate test repository on GitHub,
   Mathew-18/DH_Construction_Phase1_Test.
2. Before uploading or enabling Pages, remove CNAME from the extracted
   test copy. The original CNAME in this ZIP points to dhconstruction.co.in.
   If CNAME is already in the test repository, remove it there before
   enabling Pages. Leave the test repository's Custom domain field empty.
3. On the test repository's main branch, choose Add file > Upload files.
   Upload the extracted files and folders, preserving their paths and
   capitalization. Put index.html at the repository root. Commit the files
   to main. Upload the extracted contents individually, without the ZIP
   or an extra containing folder.
4. In the test repository, open Settings > Pages. Choose Deploy from
   a branch, select main and / (root), then click Save.
5. Wait for Pages to show that the site is live. Open the preview link
   displayed in Settings > Pages, then check the navigation and services.

Some styles, fonts and photos use external services and load when your
browser can reach them. The archive retains the original asset references.
